# 🍽️ OOTA – Tiffin Shop Website

A tiffin Shop website designed to showcase delicious food, explore menu offerings, and provide information about catering services.Tiffin Shop Website

### Redefining Vegetarianism

OOTA is a tiffin Shop website designed to showcase traditional and delicious vegetarian cuisine. It provides visitors with an engaging way to explore the tiffin Shop, discover its menu, and learn about its catering services.

## 🌿 About the Project

OOTA aims to create a simple, attractive, and user-friendly digital experience for customers looking to explore vegetarian food and catering offerings.

## ✨ Features

- Attractive restaurant landing page
- Tiffin menu showcase
- Catering services information
- User-friendly navigation
- Visually engaging design
- Responsive website experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
